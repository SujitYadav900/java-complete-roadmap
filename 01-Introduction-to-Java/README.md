# 01 — Introduction to Java

> Welcome! This is your **very first step** into Java. In this module you will learn what Java is, where it came from, why it is so popular, and how a Java program actually works behind the scenes. No prior programming experience is needed.

## 🎯 Learning Objectives

By the end of this module, you will be able to:

1. ✅ Explain what Java is and why it was created.
2. ✅ List the key features that make Java platform-independent.
3. ✅ Distinguish between the JDK, JRE, and JVM.
4. ✅ Describe the complete Java compilation and execution flow.
5. ✅ Write and run your first Java program.
6. ✅ Answer common beginner interview questions about Java.
