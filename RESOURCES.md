## 📌 How to Use These Resources

1. **Module-first policy:** Follow this repo's modules as your main path. Don't get lost in endless videos.
2. **Docs when stuck:** If a concept in this repo is unclear, open the official docs link for that topic.
3. **Practice daily:** 30 minutes of HackerRank/LeetCode beats 3 hours of passive watching.
4. **Reference books later:** Read *Effective Java* after module 16 — it assumes Java knowledge.
5. **Version awareness:** Java 17/21 LTS is the industry standard in 2026. Prefer LTS versions.

> **⚠️ Warning:** There are thousands of "Java courses". Trust the official docs, this roadmap, and the resources above. Too many resources cause *tutorial hell* — pick one path and finish it.
